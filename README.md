# 🩺 МЕДИКА — онлайн-запись к врачу

**Забота о здоровье начинается здесь.**

МЕДИКА — демонстрационный веб-сервис медицинского центра, созданный на Python и Flask. Позволяет выбрать медицинское направление, врача, дату и свободное время приёма, заполнить данные пациента и подтвердить запись.

## ✨ Возможности

| Функция | Описание |
| --- | --- |
| Каталог специалистов | 16 медицинских направлений, по 6 демонстрационных карточек врачей |
| Календарь | Запись на ближайшие 30 дней |
| Расписание | Интервалы по 30 минут, начало приёмов с 08:00 до 12:00 |
| Свободное время | Занятые и прошедшие интервалы недоступны |
| Данные пациента | ФИО, СНИЛС и дата рождения |
| Подтверждение | Сохранение записи в SQLite и страница подтверждения |
| Защита от двойной записи | Уникальное ограничение на врача, дату и время |
| Интерфейс | Адаптивный дизайн в мятных и пастельных тонах |
| Анимация | Плавное движение медицинской иллюстрации на главной странице |

| Терапия | Хирургия | Офтальмология | Оториноларингология |

Все имена врачей вымышлены и предназначены исключительно для демонстрации интерфейса.

## 📅 Как работает запись

1. Выберите медицинское направление.
2. Выберите врача.
3. Укажите дату и доступное время.
4. Заполните ФИО, СНИЛС и дату рождения.
5. Подтвердите запись.

Сервер проверяет обязательные поля, формат СНИЛС (11 цифр), дату рождения и допустимость времени. Если другой посетитель уже занял выбранный интервал, повторная запись отклоняется.

## 🗄️ База данных

SQLite создаётся автоматически при запуске приложения: `instance/clinic.sqlite3`.

| Таблица | Назначение |
| --- | --- |
| `doctors` | Идентификатор, специальность, код и имя врача |
| `appointments` | Врач, дата, время, данные пациента, уникальный код записи и дата создания |

Связь между таблицами — один врач ко многим записям. Ограничение `UNIQUE(doctor_id, visit_date, visit_time)` предотвращает двойное бронирование, включая одновременные запросы.

При запуске приложение создаёт необходимые таблицы, добавляет недостающие поля и обновляет демонстрационные имена врачей без удаления существующих записей.

## 🚀 Запуск

### GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Denis-create-boop/to_doctor?quickstart=1)

В терминале:

```bash
python -m pip install -r requirements.txt
python main.py
```

Откройте порт **5000** через **Open in Browser**. Используйте приватный порт для демонстрации.

### Локальный запуск

```bash
git clone https://github.com/Denis-create-boop/to_doctor.git
cd to_doctor
python -m venv .venv
```

Активируйте виртуальное окружение: Windows — `.venv\Scripts\activate`, Linux/macOS — `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python main.py
```

Откройте [http://localhost:5000](http://localhost:5000).

## 🔒 Ограничения и безопасность

- Проект учебный, не является действующей клиникой. Используйте **только вымышленные персональные данные**.
- СНИЛС проверяется по формату, но не по контрольному числу и не через государственные сервисы.
- Расписание демонстрационное, одинаковое для всех врачей, без учёта выходных.
- Исторические записи из старых JSON-файлов не перенесены автоматически.
- Личный кабинет, административная панель, уведомления и отмена записи пока не реализованы.
- SQLite содержит данные в незашифрованном виде. Для реальной эксплуатации необходимы надёжная авторизация, защита персональных данных, управление доступом, резервное копирование и безопасное развёртывание.
- В приложении предусмотрены CSRF-токены, параметризованные SQL-запросы и ограничения базы данных.
